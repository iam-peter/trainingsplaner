Hinweise

Unabhängiges Projekt

Ein unabhängiges Projekt. Es steht in keiner Verbindung zum IAT Leipzig, zum BVDG oder zu WinWoTA; die Namen nennen nur, welches Programm und welches Datenformat ersetzt werden.

Lizenz

Der Trainingsplaner ist Open Source unter der MIT-Lizenz. Er verwendet Qt unter der LGPL v3.

Schriften: Inter und JetBrains Mono, beide unter der SIL Open Font License 1.1. Symbole: Lucide unter der ISC-Lizenz.

Daten

Das Programm speichert alle Daten lokal auf Ihrem Rechner. Trainingsdaten werden nie übertragen. Nur um neue Versionen zu melden, fragt es beim Start höchstens einmal am Tag die öffentliche Schnittstelle von GitHub nach der neuesten Version; GitHub erfährt dabei die Programmversion und, wie bei jedem Abruf einer Webseite, die IP-Adresse. Die Abfrage lässt sich unter Einstellungen › Allgemein abschalten. Diese Webseite lädt keine Schriften oder Skripte von Dritten; für die Anzeige der neuesten Version fragt sie die öffentliche Schnittstelle von GitHub ab.
